# AirPods Pro 3 · 交互原理图解

[打开互动网页](https://ysj-lxc.github.io/airpods-pro-3-interactive/)

拖动旋转三维耳机；点击电池与触控柄，体验能量、按压和滑动示意；探索降噪、播放与红外 PPG 心率感测。
